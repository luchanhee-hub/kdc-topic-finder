전체 분류표

KDC의 함수화

KDC의 단계적인 분류 구조는 세부 주제에서 강목을 거쳐 주류로 이어지는 두 함수로 표현할 수 있습니다.

집합 A · 세목 단계

구체적인 하위 주제의 분류기호입니다.

집합 B · 강목 단계

10단위 분류기호입니다.
예: 180 심리학

집합 C · 주류 단계

100단위 분류기호입니다.
예: 100 철학

첫 번째 함수 f : A → B

f(x) = 10m

여기서 m은 x를 10으로 나누었을 때의 몫입니다. 즉, 세부 주제의 분류기호를 해당 강목으로 대응시키는 함수입니다.

두 번째 함수 g : B → C

g(y) = 100n

여기서 n은 y를 100으로 나누었을 때의 몫입니다. 즉, 강목의 분류기호를 해당 주류로 대응시키는 함수입니다.

합성함수 g ∘ f : A → C

두 함수를 차례로 적용하면 세부 주제에서 강목을 거쳐 주류로 이어지는 분류 과정을 하나의 합성함수로 나타낼 수 있습니다.

(g ∘ f)(x) = g(f(x))

예를 들어 세부 주제의 분류기호 x가 함수 f를 통해 180에 대응한다면, 함수 g를 통해 다시 100에 대응합니다. 따라서 (g ∘ f)(x) = 100이 됩니다.

자료 기준: 사용자가 제공한 「한국십진분류법 제6판 강목표」 이미지입니다. 원본 표에서 분류명이 비어 있는 260, 610, 970은 검색 목록과 전체 분류표에서 제외하였습니다. 함수화는 KDC의 숫자 구조를 단순화하여 표현한 탐구용 모형입니다.
